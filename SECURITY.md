# Política de Segurança

Caso encontre alguma vulnerabilidade de segurança:

- não abra issue pública
- reporte diretamente aos mantenedores
- forneça detalhes para reprodução
- aguarde validação antes da divulgação

---

# Escopo

A política cobre:

- APIs
- autenticação
- infraestrutura
- aplicações web
- aplicações mobile
- integrações TEF
